# Smoke Quit

A small offline Android app for tracking a smoke-free journey.

## Features

- Smoke-free day counter
- Estimated money saved
- Estimated cigarettes avoided
- Simple milestones
- Local/offline storage
- Reset/update goal
- GitHub Actions APK build

## Build on GitHub

1. Upload this project to a GitHub repository.
2. Open **Actions**.
3. Select **Build SmokeQuit APK**.
4. Run the workflow.
5. Open the completed workflow run.
6. Download the **SmokeQuit-debug-apk** artifact.

The app is a self-tracking tool and does not provide medical advice.
